Engine Project Summary
Project Overview

This project is a custom 3D game engine written in C with SDL2 and OpenGL. Its primary goal is to understand and implement the fundamental systems behind modern game engines rather than relying on existing engine frameworks.

The engine began as a terminal-based pseudo-isometric tile project before evolving into a software renderer. After manually implementing the graphics pipeline—including perspective projection, clipping, wireframe rendering, and triangle rasterization—the renderer transitioned to an OpenGL backend. The focus has since shifted from implementing graphics algorithms to designing scalable engine architecture.

The long-term goal is to support an open-world survival game inspired by the environmental scale of Skyrim, the player freedom of Minecraft, and the systemic gameplay of Valheim. Rather than focusing solely on rendering, the engine is being built around coherent world simulation, including physics, terrain representation, streaming, object management, and gameplay systems.

Rendering Architecture

Rendering is now performed through OpenGL using a scene-oriented architecture. The original software renderer served as a learning exercise and has since been replaced with a GPU-accelerated pipeline.

Current rendering features include:

    OpenGL rendering backend
    Matrix-based transformation pipeline
    Independent object transforms
    Scene generation framework
    Basic mesh rendering
    Palette-based texture system
    Camera-independent rendering

Objects exist in local space and are transformed using model matrices before being viewed through an independent camera and projected for rendering. This architecture provides a clean separation between scene management, object transforms, and rendering.

The current texture system uses a palette texture functioning as a large RGB gradient. Meshes reference colors through UV coordinates, allowing uniform coloring while using the standard texture sampling pipeline. This approach minimizes texture memory while remaining compatible with future material and texturing systems.
